反照率：按原 linen `(0.86,0.85,0.81)` 以及原白壳/黑窗表面积加权值校准新家具的 Base Color 通道均值；新脚和小五金由主体适度补偿，而非整体压暗家具。**这是低频颜色通道平均值保持，不是光输运等价证明**：实际曲面面积、凹面遮挡、材质金属/粗糙度和路径都改变，旧 GI 不能据此宣称仍正确。

## 接入顺序及仍是中间态的部分

1. 从原 linen / plasterw / iron 聚合网格中按原十个家具盒件的确切连通组件替换，不能隐藏整个材质节点（会误删墙体等）；原源继续保留。
2. 对替换后的完整公共楼生成独立 GLB 与 Blend，给出新源签名，真实重烘静态 AO、接触、整楼闭/半开/全开 GI，不能修改旧 GI hash 伪装相容。运行时仅在这些数据对应同一候选时开启显式家具候选。
3. 旧包络可用于家具简化碰撞，但必须确认当前物理系统实际采用它；本轮仅验证几何包络，不声称已实现家具碰撞。室内路线需重走。
4. 同原公共楼机位验收材质、地面接触和窗边光照、全楼往返与性能，再决定默认采用。

仍是中间态：沙发缺少更细的布料褶皱、使用痕迹与不同户型配色；家电为无品牌通用造型、深色滚筒表面并非真实透明玻璃输运，烘干机暂无外观型号差异，旋钮/抽屉等尚不可互动。原柜台与餐椅硬边另行推进。完整世界光照和色彩仍留原计划阶段，不因这里的中性预览提前改动。
