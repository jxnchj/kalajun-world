# 第38轮：低帧率视觉运动时间修复

已修复草/树风、水与云在低帧率下使用截断帧时间的问题。此前主循环把所有系统的 dt 截到 0.05 秒，ecology 再截一次，水自身也截到 0.1 秒；10 fps 时草、水、云只能推进约一半实际时间。

主循环现在将有限、非负的真实可见帧时间传给生态、水与环境。控制器、地形、建筑、门和其他原有安全步长仍最多 0.05 秒。各视觉系统同时拒绝 NaN、Infinity、负数及非数字，防止 uniform 被污染。未改风幅、草根、树根、材质或者水纹空间参数。

可见性和目的地准备暂停仍由原主循环管理，没有增加后台补时。原 90 个准备 tick 继续使用 0.016 秒，未改变初始化结果。

验收证据：

- 读取并实际执行 main.js 的 frame 函数，连接真实 WorldEcology/WorldWater/WorldEnvironment.update；仅渲染器和无关调度使用测试桩。
- 60、10、2 fps 与不规则帧推进相同 2.731 秒，草风 uniform、风纹理端点、树风上传、水和云相位一致。
- 非法 delta 不污染状态；隐藏和 preparing 期间不推进，恢复不补跳。
- 旧 90 次准备及风场检查通过，共 11/11。
- 修复的是运动时间语义，不代表草影形态、帧率或完整风植物动力学已完成；动态画面仍需浏览器验收。
