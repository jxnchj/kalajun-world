# 28轮溪岸候选说明

## 实际修改

- `shore-material.js` 增加 `shoreEcotoneCover`，只使用已有水分、真实水面高度差、坡度及已过滤的草甸/林下群落结构。此前0–2cm必然裸露且要到12cm才完整恢复根毡；新的群落支持缓坡在水面以上1–25mm恢复低根毡，低群落值保留沉积窗口。水面以下、干地、陡切面保持旧材质。
- `terrain-material.js` 同一覆盖同步改变裸床分类、原草甸/林下底色、法线与粗糙度，不是只把泥染绿。林下补充最高1.75cm的浅层着色起伏，使用原有2.4m草簇字段和相同像素覆盖过滤；属于材质起伏，不是新增地形/碰撞高度。
- 新增 `shore-ecotone.test.js` 验证边界、CPU/实际GLSL数值对应、实时开关、物理材料渠道一致性，以及真实林溪断面采样。
- 不增加纹理、采样器、植被、石头、绘制调用；不改变植被密度、草根位置、水位、中线、岸石碰撞、全局光照与调色。

## 对照

`?shoreEcotone=v27` 恢复本轮修改前材质；默认为本轮候选。实时：`terrain.material.userData.terrainShoreEcotone.value=0/1`，实际debug对象路径由主验收确认。

## 验证

`shore-tests.log` 25项通过。真实林溪8966个2–120mm低岸样点（使用现有群落采样、源地形与水位）平均根覆盖3.96%→21.00%；6120点仍低于10%覆盖，1764点超过50%。这是材料覆盖数值，不能代替浏览器美感评估。

原河道几何/碰撞回归：1035个真实水面顶点未穿地，43个27轮既有岸鼻最大24cm、177个其他节点保持不变；岸石完整扫描三角形与实例变换一致，连续运动及流式碰撞回归通过。

## 未采用与中间态

曾试更强岸鼻轮廓，但真实溪宽仅约1.5m，保护河宽后实际增量很小。已将 `river-section.js` 和原 `shore-lobes.test.js` 精确恢复备份27轮内容，不把无效微扰计作成果。

本轮并未重新设计整条河道，也没有消除遥感中线的所有长直段；尚需同条件浏览器判断湿岸连续带是否有足够改善。远坡大形、完整室内GI及全局光照色彩不在此子任务修改范围。近远改善仅指新增根毡着色起伏与现有群落共用尺度和过滤，不宣称远坡重复已解决。
