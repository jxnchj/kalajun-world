# 第32轮：普通土与矿物岸面的孔隙/自由水膜分离

## 当前结论

已修复一处明确的材质物理不一致，等待主任务冻结同条件浏览器AB判断它对亮边的实际贡献。不能仅凭测试把溪岸灰亮连续边、岸线长直形态、远坡构图或整体近远协调记为解决。

第30轮只保护了有机土层的孔隙粗糙度。普通土和裸露矿物层仍直接使用 `shoreWetRoughness`：含水量接近1就抛光，而没有判断是否真的存在水膜。因此低根毡覆盖、低有机层覆盖的露岸区域依然可能形成连续高光。第31轮真实射线点 (pixel 200,700；1453×839，固定林溪机位) 的插值地形低于名义水面3.59mm、却处于水体外侧7.77cm，没有水面覆盖；在饱和、dry=.9、grain=.5 的独立材料响应下，旧粗糙度=.585，新孔隙响应=.837。这是响应示例，不冒充完整浏览器像素的最终roughness。

## 实作

- 新 `shorePorousRoughness` 保留潮湿孔隙的粗糙表面，仅在水位下1.5–6cm且同源水边内侧1.5–12cm的连续过渡中启用原有自由水膜响应。
- 普通土/矿物链使用该响应；已有有机土、根毡与雪层覆盖顺序保持。真正深水底和干燥端点保持，仍保留潮湿变暗、原法线、颜色和贴图全部采样。
- 所有判据都是已有的物理米制属性，跨LOD与远近距离一致；无新的近处材质、距离阈值、碎斑或纹理读取。已有32–90m森林扫描均值/残差衔接回归通过。本轮**没有新增远坡布局/几何，也没有解决全域远近构图**。
- 水位、地形、草树位置/数量、几何细节、全局光色不变，没有添加石头遮盖亮边。
- 对照：`terrain.material.userData.terrainPoreFilm.value=0` 为完整31轮普通土湿润响应，`=1` 为新响应。URL `poreFilm=v31` 可重载旧路径。live切换不编译材质、不改场景状态。
