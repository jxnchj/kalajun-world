# Pretransformed root-sphere GPU candidate

`installPreparedTreeFrustum(mesh, control)` is an independent opt-in candidate. It returns `record.sync()` and statistics. It does not change ecology integration or any default. Call `sync()` after root matrix/count writes and before any renderer/compile call; updating in Three's draw hooks is too late because `objects.update` already uploaded attributes.

The existing complete `treeCullSphere` local geometry plus `TREE_CULL_WIND` envelope is transformed once on the CPU per original matrix version/prefix change. The instance matrix is read at its actual Float32 values. A Gram-matrix row-sum bound covers rotations, nonuniform scales, reflection and shear; float32 center error and outward radius rounding are retained. Unknown wind, position/wind source edits, morph targets, skinning, displacement maps and invalid affine matrices set a negative radius and draw everything. Original matrices, counts, ordering, root membership and detail remain untouched.

The shader transforms only the pretransformed center by the actual modelView matrix. The actual projection matrix supplies all six planes, covering normal/reversed depth, main, oblique reflection and shadow cameras. A second Gram upper bound covers the modelView linear transform. Negative plane distance is compared in squared form, avoiding six square roots. Geographic float guards are added. There is no vertex-level instance-matrix multiplication, nor a full projection*modelView*instance matrix product in this candidate.

The owned attribute intentionally uses `aTreeFrustumSphere` so the existing shared-tree geometry disposal path releases its GPU buffer. It is mutually exclusive with the earlier full-matrix culler. Allocation is 16 bytes per resident instance, once; no per-camera arrays. Existing colour/depth materials share a control but use their actual built-in draw matrices. Already-installed materials require their existing control identity.

Independent float32 replay checked 15,000 main/reflection/shadow cases under both depth conventions: all exact intersecting wind spheres are retained, and 10,702 outside cases early-reject. Other tests cover original full wind corner enclosure under nonuniform scale/shear, version/count refresh, unchanged matrices, unsupported deformation fallback and actual WebGLGeometries disposal. See `tree-prepared-frustum-tests.log`.

This is still a per-vertex test, so retained on-screen trees pay extra instructions. It should cost materially less than the old full-matrix approach, but useful benefit depends on off-screen roots within the coarse visible batches and compiler optimization. No frame-rate gain or image equivalence is claimed without actual frozen browser and GPU AB. Default adoption belongs to the coordinating task.
