## 来源与方法

`tools/measure-meadow-canopy-reference-v38.mjs` 直接调用当前 `meadowGeometry(true/false)`。源 SHA、480 组方向参考与另 216 组项目实际时刻太阳参考保存于 `tools/reports/meadow-canopy-reference-v38.json`。每个非退化三角使用实际几何面积、三个重心积分点的插值着色法线、实例高度缩放的逆转置、双面面朝向翻转；每组以 16 个均匀根方位积分。保留穗秆实际 14% 权重。高度比 .78/.955/1.13 来自原 vigor 范围，.6006 是花草竞争缩高边界；这是代表性形态测试，不假装测过全世界根部统计。静止源姿态，不包含风变形。

参考是单位漫反射叶片的可见投影面积平均，乘去共同的 1/pi。不改原色素，材质顶点颜色/根部明暗视为另一个未重新拟合的因素，镜面分量也不在本项中。参考没有射线互遮蔽或冠层覆盖，不能直接当作地表 BRDF。它检验的只是：普通粗糙漫反射能否近似真实源叶片的角度关系。

普通 Oren-Nayar 在 0–90 度 sigma 全范围搜索，预先规定单位响应 RMSE <= .04 且最大误差 <= .08 才有资格进一步接线。实际 8 组最优 RMSE .136–.184、最大误差 .300–.399；多组最优 sigma 到 90 度边界，全部未通过。不以法线方差直接冒充粗糙度标定。

典型高度比 .955 的近/中 LOD 加权面积分别 .19018/.17574 平方米，E(n_y²) 分别 .37727/.48875。中距简化曲率本身也改变了反射法线分布，所以不能只拿平地纹理解释全部距离差异；本次没有修改源几何。
