# 代表林溪树干实体候选（第 41 轮）

状态（2026-10-27 更新）：主线实景阻挡/绕行验证后授权采用；生产注入真实WorldEcology时默认启用，`ecologyCollision41=0` 可对照旧路径。历史Node调用若未提供ecology则保持旧碰撞；无源但显式 `ecologyCollision41=1` 仍明确拒绝。最终默认构建待主线复验。

## 原缺口与范围

原 `WorldCollision` 处理建筑、动态门、木步道和岸石，未处理生态树干。真实林溪树 `spruce:-301:400` 的原默认路径可直接步行到干心，这个缺口已由同根位对照复现。

岸边大石原来已经使用同一 `createShoreStones` 根位与原 1260 面扫描壳，保留现有实现；本轮回归确认同位置、同三角和滑动/攀上斜石关系，不重复放石。objects.json 没有独立大石实体表；草坡大片岩色是地形材质，与地形碰撞相符。细草、针叶和细枝不加阻挡。

## 实现

`WorldCollision` 注入正在显示的 `WorldEcology`，直接读其 `treeAt(ix,iz)`：包含现有 rootCache、ForestRootLayout、岸边修正后的最终稳定 ID、根位、变体、旋转和缩放。不复制树生成规则，不从当前可见 LOD 批次猜树根，不另播种。

五型高模树皮借用已加载源。以原 -0.25m 根盖中心为连通起点恢复 UV/法线接缝的拓扑，提取每型 **192 面完整原树干**，保留根胀、截面和倾斜；针叶和枝条连通分量不进入实体。幼树有低于根盖的垂枝，所以不能用全树最低点作为根干。保留顶点与三角而非以冠层包围盒或猜测粗圆柱阻挡。

物理窗口每移动 4m 单元刷新一次，36m 激活（含移动更新裕量）、48m 保留；源 cell 检索包含 ForestRootLayout 的 18m 最大位移 halo。只有步行物理启用时创建实体；离区、重新基准原点、禁用和释放都清理。实体固定在源根位，不随风时钟、远近 LOD 或绘制排序变化。未修改现有渲染风模型（它仍有轻微的树干弯曲）；本项保证物理树干固定，并非新增树干动画。

## 已验证

- 五型从完整原 bark 提取，各 192 面、原坐标逐一可回查，未改源顶点。
- 真实林溪根 `spruce:-301:400`：x=-3609.243411584515，z=4804.219241920092，y=2327.2103944071305，variant=3，scale=1.454025076245889。
- 候选 OFF 可走到干心；ON 被树干实体挡住、无重叠，绕行成功。
- 清空可见近树批次、改变风时钟不会改树干体；离开 300m 再回来根记录精确相同。
- 测试邻域 35 根、6720 面物理三角，原可见树密度和源资产不变。
- 与既有建筑、岸石、客房门、防夹、牧具及原门功能合并回归 **30/30 通过**，日志 `tools/reports/ecology-solids41-regression.log`。

浏览器起点建议 x=-3610.843411584515、z=4804.219241920092，y=当前 surface.heightAt(x,z)+1.6，朝上述根心走；侧退/绕到 z+1.6 再越过。使用实际渲染中的树干确认碰撞/滑动，不能仅把 Node 回归作为浏览器通过。


## 实景证据与默认兼容

`docs/previews/v2-route-craft-38/ecology41-trunk-block.json/.png` 与 `ecology41-trunk-around.json/.png` 是实际玩家步行路径：前者被同源树干挡住，后者绕过树干继续通行，movement均为walk、errors均为空。阻挡位置32个有效树干/6144面，绕行后物理窗口35个/6720面。结合定向Rapier测试覆盖离开300m再返回、原根位不变、LOD/风不移动物理实体。

采用只增加原有可见树干的物理实体，不增加或移动树，不改其视觉细节；细草仍可穿。默认无ecology的历史WorldCollision构造不会因此失败，但显式启用缺真实源依旧拒绝。不可将测试fixture没有生态数据解释为生产允许另造树根。
