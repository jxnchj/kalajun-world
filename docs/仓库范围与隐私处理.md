# 仓库范围与隐私处理

此仓库保存截至第32轮的代码、方案、开发进度、部分验收记录、当前V2运行资产与必要Blender源。原本地项目不作删除或移动。

排除：私人旅行原照片与缩图、GPS/拍摄时间/机位对应表、儿童肖像及衍生模型、Aholo任务/余额/签名链接、录屏、账号配置、密钥、依赖与虚拟环境、历史构建、重复备份和可再生树枝数组。Git提交使用GitHub noreply地址。

公开场景地理坐标与地形数据保留；它们定义世界位置，不是个人照片的拍摄轨迹。scene.json中的私人viewpoints已清空，照片工具从忽略的本地配置读取。

所有上传的Blender编辑源在副本中使用已审核的非私人纹理并清理本机绝对路径；必要资源已打包。模型几何不以降低细节来减小仓库。相关源指纹随脱敏后的源更新，运行GLB不因为改路径而重建。

少量assets/src/v2/spruce/backup-*目录属于现有测试明确读取的固定基准，并非上传全部历史备份。大模型使用Git LFS。预览历史中的未交付截图/日志链接可能只存在于原本地项目；方案和进度文字保留，最新路线总览随仓库交付。

本次不改变项目美术方向、密度或运行算法。后续从原开发目录同步时仍必须检查新增文件，不能整目录覆盖上传；本机脱敏审查报告不作为上传内容。
