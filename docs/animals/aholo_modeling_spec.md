# 用 Aholo 生成喀拉峻动物 3D 模型的要求（给执行建模的 agent）

## 任务
用 Aholo（群核 Lux3D，labs.aholo3d.cn）的"图片生成 3D"，为 6 类动物各生成一个 3D 模型。
每类动物的输入是用户做好的四张视图。
模型交回后，另一个 agent 会负责缩放、减面、绑骨骼、做动作和改毛色。
**你只负责生成并检查原始模型，不要对模型做任何修改。**

## 输入
| 编号 | 动物 | 四张视图（按这个顺序上传） |
|---|---|---|
| sheep | 哈萨克大尾羊 | 正右侧面、正前方、正后方、左前 3/4 |
| cattle | 牛 | 同上 |
| horse | 伊犁马 | 同上 |
| dog | 哈萨克牧羊犬 | 同上 |
| marmot | 灰旱獭 | 同上 |
| golden_eagle | 金雕（展翅） | 正上方俯视、正下方仰视、正右侧面、正前方 |

图片位置：〈用户填写放图的文件夹〉

**上传前处理图片**
- 如果四个视图画在一张横幅里，先切成四张独立的图。
- 每张裁成正方形，动物居中，四周留约 10% 白边，分辨率至少 1024×1024。
- 不改动画面内容，不重绘，不调色。

## 生成参数
- **功能**：图片生成 3D，**多张视图一起提交**（同一只动物的四张图作为一个任务）。
- **版本**：G1。
  - 想先看看效果，可以先用 G1-Turbo 试一次；正式结果必须是 G1。
- **面数**：
  - 羊、牛、马、狗：30000
  - 旱獭、金雕：20000
  - 网页上没有这个选项就用默认值。
- **PBR 材质**：G1 固定生成 PBR（官网说明），保留即可，不必关闭。后续只用其中的颜色贴图（base color），金属度、粗糙度等贴图会被忽略。
- **自动估计尺寸**：不开（尺寸由后续处理按真实肩高设定）。
- **输出格式**：GLB（带贴图）。

## 积分
- 账户里有 30 次免费 3D 生成。通过接口（API）提交的任务不使用免费次数、照扣积分，所以**优先在网页端提交**，用掉免费次数。
- 如果必须走接口：每个 G1 任务 20 积分，G1-Turbo 1 积分。**每次花积分前先告诉用户要做什么、花多少，等用户同意。**
- 不要打印、记录或复制 API 密钥。

## 检查每个模型（不合格就重新生成，同一只最多重试 2 次）
从前、后、左、右、上五个角度看模型，逐项确认：
1. **和四张图是同一只动物**：体型比例、毛色、角、尾巴都对得上。
2. **四条腿完整、各自分开**：从侧面看，腿与腿之间没有连成一片的"蹼"；四只蹄（脚）都在，底部大致在同一平面上。
3. **尾巴完整，和后腿分开**；头、耳朵、角完整。
4. **没有破洞、没有多余的肢体或碎片**，身体不扭曲，左右大致对称。
5. **颜色贴图（base color）和图上的底色一致**，没有大块的错色或贴图拉扯；颜色贴图里没有明显画死的投影或高光。
6. **金雕**：两只翅膀完整、平展，不缺羽、不粘成一块，左右对称；尾巴展开；脚收在腹下。

有问题、重试两次仍不合格的，照原样交回，并写明问题所在，不要自己修。

## 交付
每只动物放一个文件夹：`assets/src/aholo/animal_<编号>/`（编号见输入表），里面包括：
- 上传给 Aholo 的四张图，命名为 `1_right.png`、`2_front.png`、`3_back.png`、`4_front_left_34.png`。金雕命名为 `1_top.png`、`2_bottom.png`、`3_right.png`、`4_front.png`。
- Aholo 输出的原始 GLB（不改名也可以）。
- 一份记录 `record.txt`，写明：
  - 提交方式（网页或接口）
  - 任务 ID、版本、面数等参数
  - 生成时间
  - 花了多少积分或用了几次免费次数
  - 第几次生成，以及上面六项检查的结果

如果用本项目自带的命令行工具（`tools/aholo.py`），例如：
```
tools/.aholo/bin/python tools/aholo.py image 1_right.png 2_front.png 3_back.png 4_front_left_34.png --name animal_sheep --faces 30000
```
结果会自动保存到 `assets/src/aholo/animal_sheep/`，并生成 `record.json`。用前先跑 `prices` 和 `balance`（免费）。

## 不要做的事
- 不要减面、重拓扑、缩放、旋转、绑骨骼、加动作、改贴图或改颜色。
- 不要合并或拆分模型。
- 不要用文字生成 3D 代替图片生成。
- 不要把模型放进 `web/public/`。
