# 喀拉峻草原动物：四视图生图要求（交给 Aholo 建模用）

版本：2026-10-14 第 2 版

**怎么用**
- 你按这份要求为每类动物做好**四张视图**，交给我。
- 我交给 Aholo 生成 3D 模型，再绑骨骼、做动作，放进场景。
- **每类动物只做一个模型**。不同的大小、毛色、花纹，都在场景里由我按个体改，所以生图时**毛色要做成"底色版"**（见下文第四节）。

## 二、每类动物要的四张图

同一只动物、同一个姿势、同样的毛色和比例，四张图之间要能对上。

| 图 | 四足动物（1–5） | 金雕（6） |
|---|---|---|
| 1 | **正右侧面**（最重要，比例以它为准） | **正上方俯视** |
| 2 | 正前方 | 正下方仰视 |
| 3 | 正后方 | 正右侧面 |
| 4 | 左前方 3/4 | 正前方 |

- 四足动物的镜头齐身体中部高度；3/4 视角那张镜头略高于背部。
- 可以分成四张图，也可以在一张横幅里并排画四个视图。并排时视图之间留白、比例一致、脚底对齐，我来切开。
- 每张至少 1024×1024，最好 2048。

## 三、所有图都要满足的要求

模型要绑骨骼、做动作：走路、小跑、低头吃草、张望、甩尾、卧下、扇翅……
绑骨骼和蒙皮要求身体各部分在图上清楚分开，所以下面关于姿势的几条最要紧。

**画面**
- 一张图只有一只动物，全身完整，四周留约 10% 的空白。
- **纯白背景**。不要地面、草、石头、阴影、文字、水印、边框。
- **长焦、正交感**：透视很弱，不要广角变形。

**姿势（四足动物）**
- **自然站立的展示姿势**：四条腿伸直、竖直着地，左右略分开。
- **前后腿不交叉、不重叠**：从侧面看，四条腿之间都能看到背景。
- **头颈平举向前**。不要低头吃草，不要回头，不要歪头。
- **嘴闭着**，耳朵自然张开，不贴在头上。
- **尾巴自然下垂，和后腿之间留出空隙**。
- 身上不带东西：不要缰绳、马鞍、铃铛、项圈、绳子。
- 左右对称，身体正直不扭。

**姿势（金雕）**
- **双翅完全展平张开**，像滑翔一样，翼尖的飞羽像手指一样分开。
- 尾巴展成扇形，双脚收在腹下，身体水平，头朝前。
- 翅膀不能有任何遮挡和折叠：这是给翅膀绑骨骼用的基准姿势。

**光照与画法**
- **光照均匀柔和，没有投影、没有高光**，像阴天的散射光。贴图里不能把光影画死，场景会自己打光。
- 风格化写实：比例、结构照真实动物，画法柔和、干净、概括，类似《塞尔达传说：旷野之息》。
- 毛发用大块面表现，不画一根根的细丝；羊毛是成团的卷块。
- 颜色柔和、略降饱和、偏暖的土色。
- 眼睛自然深色，不要卡通大眼。

**负面提示词**（工具支持就加上）
```
地面, 草地, 阴影, 投影, 文字, 水印, 边框, 多只动物, 低头, 回头, 歪头, 张嘴, 腿交叉, 腿重叠, 尾巴贴腿, 缰绳, 马鞍, 项圈, 铃铛, 花纹斑点（除非下文要求）, 强烈高光, 戏剧性光照, 广角透视, 卡通大眼, 细毛丝, 照片噪点, 残缺或多余的肢体
```

## 四、毛色：做成"底色版"

场景里的花色变化，是我按身体部位（头、脸、腹、腿、鬃尾等）在贴图上重新上色做出来的。
所以生图时毛色要**简单、均匀、分区清楚**，不要画花纹、斑块、脏污。

| 动物 | 生图时用的底色 |
|---|---|
| 羊 | 全身均匀的浅奶白色羊毛；脸和腿是同色系、稍深一点的米黄色 |
| 牛 | 全身均匀的中等褐色；口鼻周围一圈浅灰白；角浅色、角尖深色；蹄深色 |
| 马 | 骝毛：身体均匀的红褐色，鬃毛、尾巴和膝盖以下为黑色；脸上和腿上没有白斑 |
| 狗 | 全身均匀的浅奶黄色，口吻稍深 |
| 旱獭 | 均匀的黄灰色，背部略深，腹部浅黄 |
| 金雕 | 深褐色，头顶和后颈金黄色；翼下没有白斑 |

## 五、提示词

每段提示词都由三部分拼成：**风格前缀 + 动物描述 + 视图**。

**风格前缀**（每张都加）
```
风格化写实的动物参考图，比例和结构照真实动物，画法柔和干净、概括（类似《塞尔达传说：旷野之息》），毛发用大块面而非细丝，颜色柔和略降饱和、偏暖；均匀柔和的散射光，无投影、无高光；纯白背景，单只动物，全身完整入画，长焦正交视角，透视很弱。
```

**视图**（四足动物，每张换一句）
```
视图：正右侧面，镜头齐身体中部高度。
视图：正前方，镜头齐身体中部高度。
视图：正后方，镜头齐身体中部高度。
视图：左前方3/4角度，镜头略高于背部。
```
**视图**（金雕）
```
视图：正上方垂直俯视。
视图：正下方垂直仰视。
视图：正右侧面，镜头与身体同高。
视图：正前方，镜头与身体同高。
```
