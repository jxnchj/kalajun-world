# 局部根毡剖面细节候选（OFF）

这是按米制设计的少量纤维根与根颈，供 bank50 的 middle-root-lobe 朝水侧坡配套试用；不是现场扫描或已核实物种，也尚未贴合、接入生产场景。没有修改原 521 株植物、任何根 ID、运行源码或公共生成数据。

## 文件与实际尺寸

- `root-mat-section.blend`：105 个可独立编辑的 Bezier 曲线路径，复用一个六边形管截面；4 个不等距根颈、35 条主根、48 条分根、18 条浅层横向纤维。不要将 `PREVIEW ONLY` 土块当作资产。
- `exports/root-mat-section.glb`：标准 glTF，只有两批真实立体根网格，426,684 字节、15,204 三角形、10,374 个导出顶点。无透明卡、无纹理采样。
- `preview-soil-context.png`：带 10 cm 尺的侧坡参照预览；`preview-root-structure.png`：隐藏土体的根系结构检查。两张均为实际 Blender Cycles 渲染。
- `asset.json`、`validation.json`：实际尺寸、源/导出绑定及加载验证。

Blender 包围尺寸为沿岸 **52.99 cm**、朝水 **25.00 cm**、竖向 **21.69 cm**。主根起始直径约 1.3–2.4 mm；根颈中部最粗约 5.14 mm。根尖逐渐收细，最细末端约 0.033 mm；这些末端用于近处收尖，不宜当成中远景可见覆盖。根不是沿整岸均匀铺开的绳子，部分线段隐入土体；代表坡面上约 54.6% 导出顶点埋藏，最大突出约 6.32 mm。

两种标准 PBR 材质为暗赭棕主根与稍暖的细根，roughness 0.91/0.88，metalness 0。没有把 AO 写成 RGB，没有使用森林顶视落叶照片冒充根剖面。预览土块为中性尺度参照；真实湿土/根土层质感由主线侧坡材质负责。

## 后续贴合边界

限定在原 middle-root-lobe 的 offset 1.5 附近，沿岸约 ±0.275 m、水缘外 0.06–0.32 m。尺寸不规则边端约多出数毫米，最终以实际支持域裁定。原树根核心及保护权重不得改动，不沿整岸重复平铺。

局部原点是候选土体上缘中心。Blender X 沿岸、Y 朝水、Z 向上；导出 Three 坐标为 `(X,Z,-Y)`。本段沿岸方向约 `(-0.013555906, 0, -0.999908114)`，朝水方向约 `(-0.999908114, 0, 0.013555906)`。因此 glTF 的 X 轴映射沿岸、Y 轴映射竖直、Z 轴映射背水方向。

**不能直接把整块挂在标记点上。** 当前根形按照约 26 cm 水平行程/22 cm 下降的代表坡面设计；真实接入前须读取同一 `heightAt` 与朝水侧坡，调整曲线或顶点，使根起点、末端和埋藏段进入土体，仅露短段，并将可见根颈对应现有植株位置。土层下端应在水位以上约 2 cm，上端在冠顶以下约 4 cm。未做生产坡面接地、动态植被接触或浏览器采用验证。

## 编辑与重新导出

项目根目录执行：

```sh
tools/.bpy/bin/python tools/blender/v2_root_mat_section.py --export-existing --preview
node tools/check-root-mat-section.mjs
```

`--export-existing` 从已经编辑保存的 `.blend` 导出，不从程序重建根形。保留根对象的 `rootRole` 属性和共享截面。GLB 自动按两种材质合批，源中仍是独立曲线；预览土块、尺、灯、相机都不导出。编辑父根后，分根连接点也需一起检查，当前没有自动绑定约束。

初次生成命令是不带 `--export-existing` 的同一脚本；如果源文件已存在会明确拒绝覆盖。第一版等距根团已保留在 `iterations/first-brooms/`，不作为最终候选。

实际 GLTFLoader 回读已通过：轴向/尺寸、有限单位法线、所有三角形非退化、两种不透明 PBR 材质、代表土体内外都有根段；编辑源也已用 Blender 重新打开验证。最后一次从保存源重新导出的 GLB SHA 未变。当前形态仍是局部纤维根细节候选，不能将离线通过写成完整根岸或第三阶段完成。
