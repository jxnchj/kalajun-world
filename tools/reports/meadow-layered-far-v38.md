# 独立远草四命中层候选

此候选不导入生产入口，不修改真实根位、密度、地形或完整光色方案。

## 已知实测与变更依据

原 128² / 25° / 方位 0° / middle / 4×MSAA 捕获没有 GLSL 错误，但不能作为单法线远草：342.788 个投影草像素，方向参考能量 195.4902，平均法线预测 190.6234，相对误差 2.48954%；仅 8 个 alpha=1 像素，RMSE 0.09485115，max 0.20651683。完整 alpha 也可能由 4 片不同叶片分别覆盖 4 个样点，平均法线与平均可见性相乘无法保留非线性截断和二者相关性。

改用 256² 非 MSAA 捕获，每个 128² 目标像素保留 2×2 的 4 个独立源命中。每个命中保存原 albedo、实际双面 normal、精确单采样 packed depth、中心 coverage；先分别算光和阴影，再合成覆盖，不平均 normal 后照光。未命中为真实透出，不删混合边缘。2×2 的规则样点与浏览器硬件 MSAA 位置不同，必须通过真实图像比较，不宣称逐像素等价。

## 可实际渲染的输出

`web/src/v2/meadow-layered-far-v38.js` 的 `createMeadowLayeredFar38` 直接返回 Three.js mesh/material/textures，独立场景可加入显示。`mode=0` 原色，`mode=1` 单位方向响应，`mode=2` 原色乘实时方向光及调用方明确提供的 ambient。无预烘光照写入 albedo。

`updateLight(lab.light)` 绑定独立源场景的 BasicShadowMap 原生深度和矩阵，逐命中的实际世界位置、normal bias、shadow bias/intensity 参与实时阴影；严格拒绝 PCF comparison sampler。当前依靠原源几何继续投影以验证自遮挡，没有把自遮挡成本伪称已消除。源几何仍保持所有 55 根。

覆盖为 0.25 / 0.5 / 0.75 / 1；透明混合保留地表透出。合成片元只用最近命中测试场景深度且不写深度，避免把混合深度当精确实体。新遮挡物穿过一个输出像素内不同命中时可能仍有误差；捕获方向变化、背后不可见叶片、连续视角过渡仍需解决。此项是可视局部候选，不是已采用的世界 LOD。

## 成本

每方向 256² × RGBA8 × 4 = 1,048,576 B 无 mip 纹理；12 方向为 12 MiB，未计 gzip 传输（需真实 GPU 捕获后下载计算）。局部绘制 1 draw / 2 tri，最多 16 次源纹理 + 4 次阴影深度 fetch。四层没有额外复制数组到 4 张层纹理，直接寻址同一 256² 源纹理的 2×2 子样点。

## 验证

`node --test web/src/v2/meadow-patch-reference-v38.test.js web/src/v2/meadow-layered-far-v38.test.js`：7/7。

包括真实 55 根和原 near/middle 几何属性一致；异常后 renderer 恢复；render 后反向投影保存；非 MSAA 深度；相反法线与相关阴影导致平均 normal 错误而四独立命中正确；混合边缘不丢弃；拒绝将旧 MSAA 捕获当分层源；拒绝错误阴影 sampler。

下一验收是实际 256² singleSample 捕获的分层响应误差与同条件源草截图；通过后才判断局部画面候选，不先接生产。

## 第一轮真实透视截图：未通过

1280×800 / 62、70、78m 原几何与原固定 2×2 候选分别有 1312 / 1043 / 828 个差异像素，最大通道差 146 / 123 / 151。相同 ROI 高于灰地面31的亮度总量分别约减少30% / 25% / 34%；此指标是正对比量，不是物理辐照度。78m 原色绿色正对比4660→4070，约减少12.7%，因此不能用逐命中方向能量通过来代替真实覆盖验收。

完整数值：`docs/previews/v2-route-craft-38/meadow-layered-comparison-v38.json`。局部5倍显示：同名 HTML，以 CSS 展示原 PNG 的 x570–710/y350–445，不修改原图。

已修复两处具体采样/投影错误，待浏览器复验：

- 原固定 2×2 atlas 最近邻与实际屏幕像素的投影面积不同，在62–78m出现漏取/重复取。现在按 dFdx/dFdy 足迹精确计算涉及原始 texel 的面积权重，每个命中独立算光与真实阴影。通常9–16个命中、45–80次fetch；比首版20次更贵，不假称性能改善。最大7 texel足迹，超过显示明显紫色提示而非悄悄漏采样。
- 原20m正交捕获无法直接映射到70m透视相机，仅写源depth不能补偿颜色的位置。预览已显式使用70m透视捕获与12m投影窗，70m视点数学匹配；62/78m离捕获位置的视差仍需实测，尚未解决一般新视点遮挡。

预览初始太阳已与UI25一致；`window.meadowLab.setChannel('coverage')` 可比较纯覆盖，`setSun(25)` 切实际光向。相关7项定向回归再次通过，包含真实70m反向透视投影保存。

## v3完整浏览器验收及不采用结论

独立Chrome标签，1280×800、DPR1、62/70/78m，实际保存21张原几何/候选 coverage、response、albedo和空地基线；另保存70m阴影开/关4张。无shader/console错误。已关闭独立标签并清除viewport override；没有测量性能，也没有把其他Blender工作并行时的耗时当GPU成本结论。

用空地基线和纯白coverage解算前景覆盖，再减去未覆盖地面，结果：

|距离|覆盖相对差|原色绿通道能量差|方向光响应差|
|---|---:|---:|---:|
|62m|-6.52%|-6.31%|-21.14%|
|70m|-5.16%|-4.89%|-22.03%|
|78m|-6.00%|-6.61%|-19.89%|

70m双方关闭阴影后响应差仅-4.41%，按覆盖归一后候选+0.79%。开阴影时按覆盖归一的响应从原草0.51373降为0.42231。证据将主要额外损失定位到捕获depth重建后实时自阴影取样；不能据此宣称精确数值根因已经证明，浮点重建与原顶点阴影插值差异仍需区分。

量化在 `meadow-footprint-v3-measurements.json` 和 `meadow-footprint-v3-shadow-isolation.json`，可读局部5倍显示为 `meadow-footprint-v3-comparison.html`，均在 `docs/previews/v2-route-craft-38/`。前一常量64循环期间的工具暂停随后自行恢复，未证明由shader编译导致；动态有界循环只是减少展开风险。

**不采用当前候选作为世界远草。** 55根原草总计3795三角，而当前候选每方向1MiB、通常45–80fetch，并仍依赖源草投影，既未达到实际画面要求，也未建立整坡净性能/内存收益。保留真实根位捕获及逐命中光照参考工具；不接生产，不靠抬亮度、增加阴影bias或删轮廓规避失败。进一步精准重投影自遮挡需真实表面位置或三角命中信息等新数据，不能再把平均depth当同一实体表面。当前阶段停止扩展此实验页，主线应继续其他已验证的新场景内容。

生态源码花避让变更后，原导出工具已真实再生成source包（79,785B gzip）；导出前后所有55根完整字段、near/middle全部attributes/index、ground逐值完全一致。7/7定向回归通过。

### 方向响应查表的边界（只读评估，未采用）

停止扩大每命中 atlas 及远坡 LUT 实验。真实55根的方向覆盖/自遮挡响应可以形成视向方位×视向仰角×光向方位×光向仰角的4维表；粗480 RGBA16F节点约3.75KiB，较密5376节点约42KiB，但这些只是存储估计，不是验证结果。现有捕获没有完整保留叶片对可见地面的自阴影；也没有半角留出样本证明插值误差。低掠视角下，有限草块的高出地表轮廓与视差不可能由单一地表响应表保留，地表投影面积接近零时归一化还会失稳。不能把小表体积当作整坡可用证据。没有生成新表、接入生产或改近草淡出；主线回到溪岸真实切削面材质。
