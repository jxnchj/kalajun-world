# 36 米河弯沉积材料候选64（独立 OFF）

候选已实现并完成针对性 Node 检查，尚未接入主入口、构建或进行浏览器图审。正式默认49、已采用的 facies44 外岸恢复、bank50 和 root-mat 状态均未改。

## 改变及边界

沿现有8个地貌位置处理细料沉积：浅滩和安静水湾形成有方向、宽缓的细矿物／腐殖质材料，原粗砾核心保留原材质。新层严格限制在实际水域一侧，水缘内6厘米平滑回接原材质；外岸、根毡顶盖和干燥沉积资格不被重新覆盖。颜色、微法线、粗糙度共用同一个归一化权重。

露出部分保持原2.9米扫描、原细节和法线；细料区使用已有土壤采样的自身细颗粒法线与粗糙度，不是把整张砾石缩小、模糊或统一染棕。未新增规则小石、灯光修正、纹理或几何。这里是依据已有设计地貌的材料组织，不是现场沉积测量或水动力模拟。

## 最小安装

新增模块：`web/src/v2/reach-bed-facies64.js`；测试同名 `.test.js`。在 `createTerrainMaterial()` 已安装 surface41/facies44 后、首次编译前，由主线安装：

```js
const facies64 = installReachBedFacies64(terrain.material, { enabled: false });
facies64.setEnabled(true);  // 首次启用安装钩子
facies64.setEnabled(false); // 此后可同一编译程序开关比较
facies64.setDiagnostic(true); // RGB：原基材／细矿物／细有机沉积
facies64.dispose();
```

默认 false 不改原钩子、shader 文本或 cache key。dispose 仅撤自己仍持有的钩子，不释放借用的材质/纹理；后装的其他钩子不会被覆盖。若采用 URL 开关，现 Worker 严格策略会拒绝未知参数，主线需另行加入明确二值的纯材质参数；本任务没有改 Worker 或 main。

## 实际原地貌样本检查

使用当前默认49真实世界，71个沿程站×13个横断位置，共923点；284个水域外样点保持原权重。固定 meso=.5 用于材料分类检查，以下不是屏幕面积或美术通过结论。

| 段 | 湿床样点 | 细料平均权重 | 细料>60%样点 | 原材质>95%样点 |
|---|---:|---:|---:|---:|
| inlet | 207 | 41.9% | 49 | 9 |
| middle | 225 | 30.6% | 14 | 10 |
| outlet | 207 | 43.5% | 60 | 7 |

原 gravel 核心为 `[1,0,0]`；实际 -7m 浅滩附近细料约92%，-10m/8.5m 安静湾兼有细矿物与有机细料；中段仍保留较多粗砾，可由实际三机位判断分区是否足够明显。

同参数河段的 width/left/right/level、所有样点 height 均精确不变。原521个身份和 prepared/source 文件字节不变；没有重建或减少植物。5/5针对测试通过（1.334秒）：默认完整回退、真实采用材质链、统一权重、粗砾保护、空间边界和实际断面。CPU与发出的GLSL标量混合式共1452组合一致；这不是GPU驱动编译或Float32零差证明。
