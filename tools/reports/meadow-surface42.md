## 实际输入和运行

- 原数据 `/assets/v2/meadow-cluster42/meadow.json.gz`，24m，458 根，中心 `[-1972.53,2121.8634538710935,3395.88]`，保留原地面三角形与原叶实例。
- 独立构建 `node tools/build-meadow-surface42.mjs`；实际页 `http://127.0.0.1:5174/dist-v2/meadow-surface42/index.html`，按钮“烘焙与保存”。无持续 RAF，仅按钮/选择时绘制；本次 GPU 页已关闭。
- source unlit linear color/coverage、world normal 一阶与对角二阶矩、原粗糙度，共四张 256² half-float map，1024 和 2048 抗锯齿上视烘焙核对。零风，是静态来源上限，不是风动全过程。使用既有正式 source-binding plugins，不伪造 binding。
- 本次修复真实浏览器返回 gzip 已自动解码后再次解压的问题；按 magic bytes 判断。源加载与 evidence 保存均检查 HTTP 状态。
