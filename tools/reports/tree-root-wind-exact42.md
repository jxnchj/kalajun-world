# 树根风 CPU 精确复用：采用

2026-10-27。SpruceRootWind 默认启用 exactReuse42；同页 `ecology.treeRootWind.setExactReuse42(false)` 恢复原计算，`true` 恢复候选。开关使相同风时刻重新计算，保留完整根数、每帧更新、共享缓冲和原上传范围。

仅复用根的采样地址、原 Float32 旋转系数与 scratch 输出。每次读实际根位置/旋转/缩放及风网格 origin/span/resolution，变化即重算静态项；时间、风纹理内容、blend 仍使用原运算顺序逐帧计算。WeakMap 不强持有退休根。未改变全局风、可见性、密度或几何。

实际浏览器证据：`docs/previews/v2-route-craft-38/wind42-exact-reuse-abba.json`。1027 根、176 组，56,320 个 Uint32 缓冲值比较 0 差。ABBA 根风 CPU 原 1.712/1.908ms、复用 1.090/1.109ms，平均节省约 0.71ms。整帧 71.90/65.23/67.84/77.19ms 存在顺序漂移，不能将全部帧差归因于本项；GPU 23.84/23.70/24.19/24.19ms 没有净改善。这是有限 CPU 局部收益，整体林溪性能仍需推进。

针对回归 9/9 通过：非空风场、边缘内外、时间/混合、原地址直接修改、网格变化、纹理原址修改及替换、开关/释放、完整上传计数。80,927 个已有真实森林根 × 3 相位 × 5 分量，共 1,213,905 个 Float32 分量逐 bit 一致。现有森林、草甸、prepared terrain、prepared reach 来源路径均不包含 spruce-wind.js；未改生态根生成代码或源绑定，不需要重生成对应缓存。未自行主构建，等待统一构建与默认入口复核。
